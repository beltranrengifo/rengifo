# rengifo.es

My personal résumé site — from film-and-TV sound engineer to full-stack
product engineer. Bilingual (EN/ES), static and fast, with a downloadable
PDF and a second, more playful way through it: board mode.

**Live:** [rengifo.es](https://rengifo.es) · **Author:** Beltrán Rengifo

---

## Highlights

- **Bilingual (EN / ES)** via [Paraglide](https://inlang.com/m/gerre34r/library-inlang-paraglideJs):
  one language per prerendered route (`/` and `/es/`), type-safe messages,
  `hreflang` alternates and localised dates.
- **A page per project** — case studies under `/work/<slug>/` with the
  decisions worth explaining, the stack, and screenshots only where the work
  cannot be visited.
- **Board mode** at `/board/` — the career as an editorial chart: roles,
  projects and technologies as nodes on a timeline, linked by how much each
  technology was used. SVG, keyboard-accessible, with a side panel per node
  and deep links (`?node=`). Reached by clicking the cat in the footer.
- **Poncho** — an exotic shorthair drawn in SVG. On the board he walks the
  floor alongside the camera, sits, looks at what you focus, and falls
  asleep if left alone; in the footer he waits by the door to the board.
- **A real PDF** — printed from the site's own print stylesheet with
  headless Chrome, and regenerated by CI whenever content changes.
- **Share cards** — Open Graph images per language, generated from the hero.
- **Token-driven design** — palette, type and radii in a Tailwind v4 `@theme`
  block; motion gated on `prefers-reduced-motion`.

## Getting started

Requires **Node 22+**.

```bash
npm install
npm run dev        # → http://localhost:4321
```

### Scripts

| Script            | Does                                                |
| ----------------- | --------------------------------------------------- |
| `npm run dev`     | Start the dev server                                |
| `npm run build`   | Build the static site to `dist/`                    |
| `npm run preview` | Preview the production build                        |
| `npm run check`   | Type-check with `astro check`                       |
| `npm test`        | Run the Vitest suite (board data, layout, Poncho)   |
| `npm run lint`    | Lint with ESLint (`lint:fix` to autofix)            |
| `npm run format`  | Format with Prettier (`format:check` to verify)     |
| `npm run pdf`     | Rebuild the résumé PDFs in `public/` (needs Chrome) |
| `npm run og`      | Rebuild the Open Graph share cards in `public/`     |

## Editing content

- **Copy** (both languages) lives in `src/i18n/messages/{en,es}.json`. Keys
  are self-describing (`exp_mews_techlead_blurb`, `proj_ensayadero_desc`, …).
- **Structure** — roles, dates, links and projects — lives as typed data in
  `src/data/*.ts`, referencing the message keys. A project marked
  `hidden: true` stays in the data but off the site.
- **Board mode** reads `src/data/board.ts`: which technologies each role and
  project used, with a weight from 1 to 3, project dates, and the highlights
  only the board shows.
- **Design tokens** live in the `@theme` block of `src/styles/global.css`.

> `src/paraglide/` is generated from the message files at build time and is
> git-ignored — never edit it by hand.

## Workflow

Every change goes on its own branch and reaches `main` through a pull
request, using `.github/pull_request_template.md`. Merging to `main` deploys
to production and, when content changed, CI regenerates the PDF and commits
it.

## Deployment

Hosted on **Vercel**, which auto-detects Astro (`astro build` → `dist/`); no
adapter or environment variables required. Every pull request gets a
preview deployment.
